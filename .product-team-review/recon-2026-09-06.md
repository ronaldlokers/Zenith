## What the product is

Zenith — a personal job-hunt tracker that runs a search as a sales-style pipeline. Invite-only,
multi-user, deployed at zenith.lokilabs.nl. Ambition is a polished public product; the author is
the daily heavy user. Full product brief is in `PRODUCT.md` (read it — audience, positioning,
locked decisions, brand commitments). Working rules are in `CLAUDE.md` (binding).

Target user: mid/senior tech job-seekers running an active ~50-application search, daily
check-ins, mobile often one-handed between other commitments. Success = "on opening the app, know
the next action within seconds and never lose a follow-up".

## Stack and layout

- **Backend:** Cloudflare Workers + Hono. `worker/index.ts` (2701 lines) is the main router; route
  groups split into `worker/{ai,auth,calendar,cv,demo,digest,documents,feed,forwarded-email,goals,
  notifications,outreach,posting-check,public-api,push,role-types,tz,url-guard}.ts` and
  `worker/email/{index,messages,types,providers/resend}.ts`.
- **DB:** D1 (SQLite), 60 migrations in `migrations/`, applied automatically on deploy. Tables
  include applications, companies, contacts, interactions, status_history, documents, feed_items,
  feed_sources, feed_role_keywords, feed_ats_boards, feed_company_blocklist, tags, saved_views,
  interview_prep_items, journal_entries, cv_versions, work_experience, education, skills,
  languages, profile, user_goals, notifications, push_subscriptions, webhooks, outreach_templates,
  ai_credentials, rateLimit, role_types, plus Better Auth's user/session/account/verification/
  twoFactor.
- **Storage:** R2 bucket binding `DOCS` for documents.
- **Auth:** Better Auth (email/password + admin + twoFactor). `/api/auth/sign-up/email` is hard-403
  (invite-only). `/api/*` behind session middleware (`worker/index.ts:240`), `/api/admin/*` behind an
  admin-role check (`:253`). A global middleware at `:105` sets security headers.
- **Frontend:** React 19 + Vite + TypeScript. `src/App.tsx` (854 lines) is the app-shell
  orchestrator; tab bodies in `src/{dashboard,board,feed,insights,companies,contacts,detail,
  calendar,admin,cv}.tsx`, `src/cv/*`, `src/settings/*`; chrome in `src/shell.tsx`; controller
  hooks in `src/app-data.ts` + `src/hooks.ts`; API client `src/api.ts`; types `src/types.ts`;
  routing `src/routing.ts` (flat tab switcher over the History API, not a `<Routes>` tree).
- **Owned components:** 40+ self-contained components in `src/components/`, each with `*.css`,
  `*.stories.tsx`, `*.test.tsx`. Cascade layers: `src/app-styles.css` declares
  `@layer reset, app, components` (index.css=reset, App.css=app, component CSS=components).
  `src/index.css` = design tokens. `src/App.css` = one banded file. `src/utilities.css` = the only
  three globals a component may use.
- **i18n:** react-i18next, `src/locales/en.json` + `nl.json`, strict key parity enforced by
  `test-node/locale-parity.spec.ts`. All user-facing strings externalized.
- **Largest files (lines):** worker/index.ts 2701, src/board.tsx 1354, src/feed.tsx 1228,
  src/detail.tsx 1003, src/App.tsx 854, src/dashboard.tsx 833, worker/feed.ts 698,
  src/cv/sections.tsx 690, src/format.ts 674, src/pdf.ts 654, worker/ai.ts 570, src/insights.tsx 544.

## Public / unauthenticated surfaces (attack + privacy surface)

- `GET /shared/:token` — server-rendered aggregate stats page (`worker/index.ts:1923`). **Never**
  per-application detail, never compensation. Share identity controls at `/api/profile/share-*`.
- `GET /calendar/:token` — ICS feed (`worker/calendar.ts:179`).
- `/api/v1/*` — read-only Bearer API key (`worker/public-api.ts`); `applicationColumns` there lists
  exposed columns explicitly.
- Outbound webhooks (webhooks table), web push (`worker/push.ts`), inbound forwarded email
  (`worker/forwarded-email.ts`, `worker/email/`).
- `GET /api/import` fetches user-supplied URLs; all such fetches go through `worker/url-guard.ts`
  (SSRF guard), plus the `global_fetch_strictly_public` compat flag in `wrangler.jsonc`.
- Browser extension in `extension/`, bookmarklet in `src/bookmarklet.ts`.
- Cron triggers (`wrangler.jsonc`): `17 * * * *` hourly push delivery + 6-hourly feed pull
  (`shouldRunFeedPull`, worker/index.ts:2633), `11 3 * * *` R2 backup (`runScheduledBackup`:2617),
  `0 8 * * 1` weekly digest.

## Locked product decisions (do NOT propose reversing these; see CLAUDE.md / PRODUCT.md)

- No telemetry / analytics / trackers, ever. Privacy is structural.
- Invite-only, no public sign-up, no rate limits/quotas "for now".
- ~50 applications per heavy user — no virtualization; load-more where needed.
- **Light theme only.** No `data-theme`, no `prefers-color-scheme` anywhere.
  `test-node/locked-decisions.spec.ts` fails if one reappears.
- Five stage hues locked by *measured* separation (ΔE2000 ≥ 10 across normal vision + all three
  dichromacies; `--sc-ink` ≥ 4.5:1 as label text). `test-node/stage-palette.spec.ts` enforces.
  A stage's **field** colour is a tint/ring/edge, never a filled ground with type on it; the
  **ink** tones may be filled (white clears 4.5:1 on all of them).
- Pinning (`pinned_at`) is orthogonal to the pipeline: not a status, no board column, archiving
  clears the pin, the pinned view folds nothing, no cap, not on `/api/v1`.
- Public share page = aggregates only, never compensation.
- Strict en/nl key parity; more locales planned.
- Responsive parity — mobile is first-class.
- Icons are line-art SVGs, 24×24, `currentColor`, strokeWidth 2. **Never emoji.**
- Runs on Cloudflare free tier; that budget is a real design constraint.
- No pricing, licensing or commercial model decided — none may be implied.
- No formal WCAG conformance target committed (undecided).
